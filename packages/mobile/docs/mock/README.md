## 表示について（重要）

`.dc.html` は Claude Design のホスト環境で動くプロトタイプ形式（`<x-dc>` / `<x-import>` /
`sc-if` / `sc-for` のカスタム要素＋状態駆動）です。`support.js` は実行時に `window.React` /
`window.ReactDOM` を前提とするため、**素のブラウザでファイルを開いても描画されません。**

そのため本モックは基本的に「**読む**」一次資料として使ってください:

- 画面ごとの正確なレイアウト・余白・フォントサイズ・色（`var(--...)`）・コンポーネント構成は
  `.dc.html` のマークアップから読み取れます。
- 色・寸法の実値は `_ds/.../tokens/*.css` を参照（例: `--primary` = `#1585fe`、`--space-4` = `16px`）。
- 各コンポーネントの Props は `_ds/.../component-api.md`、ビジュアル原則・文言トーンは
  `_ds/.../readme.md` を参照。
