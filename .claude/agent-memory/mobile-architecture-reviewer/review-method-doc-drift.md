## 編集対象外ファイルのドキュメントドリフト

設計変更の影響を受けるのに、実装プランの「作成・編集・削除するファイル」一覧に入っていないファイルは、
JSDoc・コメント・型の説明が古いまま残る（例: 実行側が移ったのに `sessionCleanup.ts` の JSDoc が旧呼び出し元のまま、
保存 API の型が変わったのに `savedWalkId` の JSDoc が「null になりうる」のまま、ゲスト解禁後も
`AuthSessionStatus` の説明が「将来ゲストを許可する」のまま）。

**Why:** プランに従う実装者は一覧外のファイルを開かないので、構造的に毎回起きる。

**How to apply:** 変更された関数・状態・遷移を参照している**一覧外のファイル**を grep し、JSDoc やコメントの主張が
新しい実装と一致しているかを確認する。食い違いは Warning として指摘する。

## Bash が無いときの差分の特定

このエージェントには Bash が無く `git diff` を実行できない。また gitStatus のスナップショットが実際のワーキングツリーと
ずれていることがある（ブランチ切り替え後に更新されない）。依頼で渡されたプランの
「作成・編集・削除するファイル」一覧を対象リストにして、Glob / Grep / Read で実ファイルを1つずつ検証する。
