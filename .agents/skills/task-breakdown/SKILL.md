# 課題を分割する

[issue-tracker](../issue-tracker/SKILL.md) で対象本文、既存の子課題、親、マイルストーン、状態を取得する。類似実装を調べ、[粒度の指針](references/granularity.md) で機能単位に分割する。frontend/mobile/backendを機械的に別課題へ分けない。

計画のみなら案を提示して終了する。登録依頼なら既存課題との重複を避けて作成し、親子関係・マイルストーンを確認する。機能を実装する親課題は子課題を作っただけで完了にしない。元が「タスク細分化」自体の課題で、登録までが受け入れ条件なら完了を反映できる。

登録結果はID・内容・関係を報告し、途中失敗では作成済みと未作成を区別する。
