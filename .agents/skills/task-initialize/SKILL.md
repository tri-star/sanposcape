# 初期課題を用意する

既存のproject-overviewや要求を確認し、不足する重要な判断だけを質問する。MVPをdocs/mvp.mdに整理し、早く利用者に価値を届けられる機能順、開発基盤、デザイントークン、必要な認証境界を考えてマイルストーンを決める。認証を常に後回しにするなどの固定順は使わない。

[issue-tracker](../issue-tracker/SKILL.md) で既存のマイルストーンと課題を取得して重複を避ける。計画のみなら登録しない。登録依頼ならマイルストーンと、その細分化のための課題を作成する。細分化課題の本文に目的・受け入れ条件・含まれる機能を記載する。作成後に関係を確認しIDを報告する。
