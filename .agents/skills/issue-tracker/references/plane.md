# Plane 接続

MCPツールの名前と引数は実行環境から確認する。Claude用ツール名を決め打ちしない。

Plane接続用の永続メモリを使う場合、保存対象はプロジェクトIDとslugの対応だけに限り、保存自体も実行環境のメモリ規則に従う。状態・担当者・Module構成・課題の進捗などは接続ツールから都度取得する。既存メモリにそれらがあっても現在の値として扱わない。

1. 課題URL/表示IDとプロジェクト一覧から対象を解決する。番号と内部UUIDは別物。複数候補なら確認する。
2. 課題、必要なコメント、関係、状態一覧を取得する。ページングを処理し、途中のページを全件と扱わない。
3. 状態のgroupと名前から進行中・レビュー待ち・完了を解決する。review専用groupがなければプロジェクトの状態名で判断する。一意でなければ状態を新設せず確認する。
4. description/description_html等の要求形式に変換する。HTMLへ挿入する文字列はエスケープする。
5. PRはリンク機能があればそこに追加し、なければコメントへ記録する。既存URLを確認し重複させない。
6. マイルストーンはModule、課題はWorkItem。親課題・Moduleは作成後も関係を確認する。

コメントには着手内容、判断、検証/未確認、PR URLを簡潔に記載する。HTMLコメントを保持できる接続では `<!-- codex:event:<event>:<issue-id>:<pr-or-commit> -->` を使える。マーカーが消える場合は本文のイベント・URL等でも重複確認する。

他providerは取得・更新・重複防止・部分失敗の対応を別文書に実装する。共通skillにPlane固有IDを追加しない。
