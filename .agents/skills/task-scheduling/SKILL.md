# スケジュールを整理する

[issue-tracker](../issue-tracker/SKILL.md) で対象プロジェクト、未着手・進行中・レビュー待ちの課題とマイルストーンを全ページ取得する。MVP・プロジェクト目標があれば照合する。

明示された着手順・延期期間を最優先し、依存関係、作業可能人数、並列レーン、期限を合わせる。着手時期未定の課題を無理に割り当てない。直近、数か月の予定、今週期限、30日以内期限、未スケジュールを整理する。

計画のみなら管理ツールを更新しない。反映依頼なら直前に再取得し、日付・状態・マイルストーン・依存関係を必要な範囲で更新する。更新後の取得結果からスケジュールHTMLを現在のタスクの作業フォルダへ生成する。

HTMLには生成日時、project名、課題ID・URL・タイトル・状態・優先度・期限・前提を含める。URLはproviderの実URLを使い、workspace名を固定しない。順序・延期・レーン重複・マイルストーン範囲を確認する。
