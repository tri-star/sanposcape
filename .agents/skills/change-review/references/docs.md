# 文書整合性

README、共通docs/adr、変更packageのAGENTS.md・README・docs・adrが対象。ハーネスではskill、agent設定、参照スクリプト、テンプレートも確認する。関連文書だけを読む。

差異を分類する。

- 実装の不具合: 受け入れ条件や有効な設計判断への違反。
- 文書の更新漏れ: 合意した振る舞いに対し操作・設定・生成手順等が古い。
- 設計変更: ADRの前提を変える。理由・影響を残し、過去の判断を無言で置き換えない。
- 未確認: 外部サービスや実機などの証拠不足。

配置・命名・リンク・コマンドとscriptsの一致も確認する。永続文書から一時メモへ参照を作らない。
